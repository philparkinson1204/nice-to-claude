nice-to-claude 1.0.1: how polite are you to Claude?
====================================================

Needs Claude Code and Python 3.8+ as python3. On a Mac, run python3 --version
in a terminal; if it offers to install the developer tools, say yes.

1. Unzip this into your home folder, so you end up with ~/nice-to-claude

2. In a terminal, run:

     claude plugin marketplace add ~/nice-to-claude
     claude plugin install nice-to-claude@nice-to-claude

3. Restart Claude Code and type /nice-to-claude

Optional statusline counter: send one message, run /statusline, and ask Claude to use
sh ~/.cache/nice-to-claude/statusline.sh (or see "Statusline" in README.md).

Everything runs on your own machine. It reads ~/.claude/history.jsonl
and keeps a small counts-only cache in ~/.cache/nice-to-claude/.

To uninstall: claude plugin uninstall nice-to-claude@nice-to-claude
